# RouteWise & TourPulse

Complete Vite project. In a terminal, inside this folder:

```bash
npm install
npm run dev
```
Open the printed link (usually http://localhost:5173).

Quick demo: sidebar -> "Rockfall +28" -> watch the Rose Garden tour's departure move earlier,
a schedule-conflict banner appear, a map warning pin pulse, and the Disruption Radar log explain it.
